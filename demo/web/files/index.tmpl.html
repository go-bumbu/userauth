Authenticator demo

Static users (no database): admin:admin or demo:demo

Basic Auth

    Verifies credentials on every request via the Authorization header. No session is created.

  • /basic/enforce - browser prompts for credentials when not authenticated
  • /basic/silent - returns 401 silently, no browser prompt, if no credentials are provided

Password

    Log in with a username and password. On success it creates an encrypted cookie to store the auth session; protected pages check that cookie.

  • /cookie/login - login form (JSON endpoint is also supported)
  • /cookie/protected - cookie-protected page
  • /cookie/logout - logout (invalidate the cookie)

Passwordless (email code)

    Log in with just an email — a 6-digit code is shown on the next page (simulating email delivery). No password. Demo accounts: admin@example.com, demo@example.com.

  • /emailcode/login - request a login code
  • /emailcode/protected - cookie-protected page
  • /emailcode/logout - logout

HTTP Header

    Delegates authentication to an upstream service that sets the X-User-Auth header.

    Test with: curl -H "X-User-Auth: demo" http://localhost:8084/header/protected

  • /header/protected - header-protected page

All sections below share a DbManager backed by an in-memory SQLite database — data resets on every server restart.

Registration

    Username-based: supply a login name and password, account is created immediately.

  • /register - username registration

    • Email-based: supply an email and password, then verify a 6-digit code shown on the next page (simulating email delivery).

  • /register/email - email registration with verification code

Admin

    Create users and toggle their enabled state.

  • /users/ - list, create, enable/disable users

My Profile

    Logged-in users can view their account details, change their password, and update their email. Uses the database user store. Pre-populated accounts: admin@example.com / admin and demo@example.com / demo — or register your own. Accounts can also enable a TOTP authenticator as a second factor (with one-time recovery codes).

  • /profile/ - view and edit your profile (redirects to login if not authenticated)
  • /profile/login - login with a database account
  • /profile/logout - logout
